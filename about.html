About This Site

Why I made this

Understanding AI is a website I built as a school project to help students like me understand what artificial intelligence actually is, without needing any technical background. AI is becoming part of everyday life, and I wanted to make a simple, honest guide that explains both the good and the tricky parts of it.

Who this site is for

This site is mainly aimed at students in Year 10-13, but it's written to be easy enough for anyone curious about AI to follow, including teachers looking for a simple resource to share with their class.

How I built it

This site was built using HTML, CSS, and a bit of JavaScript for the quiz page. I used Git and GitHub to track my progress and publish it live using GitHub Pages. I also collected real feedback from students and a teacher to help improve the site as I went.

Feedback

This site is a student project and still a work in progress. If you spot something that's wrong, confusing, or could be improved, I'd love to hear about it.
